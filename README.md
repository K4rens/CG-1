# Computer Graphics - Lab #1: 3D Sphere Rendering in Vulkan

Реализация интерактивного приложения на **C++** и **Vulkan API**, выполняющего процедурную генерацию 3D-сферы и её рендеринг с использованием графического конвейера, матричных преобразований и интерфейса управления на ImGui.

---

## 🚀 Основной функционал (Базовая часть)
* **Процедурная генерация меша:** Сфера строится математически через сферические координаты с настраиваемым количеством секторов и стеков.
* **Управление памятью (VMA):** Эффективное выделение памяти видеокарты (VRAM) под вершинный и индексный буферы с помощью библиотеки *Vulkan Memory Allocator*.
* **Графический конвейер (Pipeline):** Интеграция скомпилированных в SPIR-V вершинных и фрагментных шейдеров[cite: 7], настройка топологии треугольников и тест глубины (**Z-буфер**).
* **Матричные трансформации (MVP):** Вычисление матриц модели, вида и проекции с помощью библиотеки *GLM* с учетом особенностей NDC-пространства Vulkan.

---

## ⭐ Дополнительные задания (Оценка 4-5)
1. **Переключение проекций:** Интерактивное переключение между перспективной и ортографической проекциями прямо в интерфейсе[cite: 3, 15].
2. **Интерактивные трансформации:** Ползунки ImGui для изменения позиции, вращения и масштаба объекта в реальном времени[cite: 3, 15].
3. **Анимация по траектории:** Автоматическое движение сферы по сложной траектории (лемниската / «восьмерка») с возможностью паузы и настройки скорости[cite: 3, 15].
4. **Управление цветом:** Палитра ImGui (`ColorEdit`) для динамического изменения цвета заливки фигуры[cite: 3, 15].
